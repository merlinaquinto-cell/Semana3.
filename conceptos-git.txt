El archivo conceptos-git.txt se menciona como uno de los entregables creados para la actividad de la semana, junto con el desarrollo de proyectos en GitHub. Con base en el flujo de trabajo técnico detallado en tus guías, aquí tienes las explicaciones solicitadas con la extensión requerida:
 * **Repositorio**: Es el espacio o carpeta virtual donde se almacena y organiza todo el código de tu proyecto, junto con el historial completo de sus cambios. Puede existir de forma local en tu computadora tras usar git init, o de manera remota en plataformas como GitHub para compartir tu trabajo y colaborar con otros.
 * **Commit**: Es una captura o "foto" del estado de tus archivos en un momento específico, guardando de forma permanente los cambios que has seleccionado previamente con git add. Cada commit funciona como un punto de control en la historia del proyecto y debe ir acompañado de un mensaje descriptivo (usando -m) que explique brevemente qué modificaciones o mejoras se realizaron.
 * **Push**: Es el comando (git push) que se utiliza para enviar y subir todos los commits y cambios guardados en tu repositorio local hacia el repositorio remoto en GitHub. Este proceso actualiza la rama remota de trabajo (por ejemplo, main) para que la versión más reciente de tu código quede respaldada de forma segura en la nube y accesible para tu instructor o equipo.
